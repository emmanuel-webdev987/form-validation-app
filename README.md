# Login and Registration System

A web-based login and registration system built using HTML, CSS, and JavaScript.

## Features
- User login form
- User registration form
- Form validation
- Show and hide password functionality
- Required field validation
- Email validation
- Password length validation
- Password confirmation matching
- Interactive user feedback

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Main entry page
- `login.html` – Login page
- `login.js` – Login functionality and validation
- `register.html` – Registration page
- `register.js` – Registration functionality and validation
- CSS files – Application styling

## Purpose

This project demonstrates my understanding of JavaScript DOM manipulation, event handling, form validation, and interactive web development.
